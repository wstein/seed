== Top-Level Structure

Seed is a single Elixir library application (`:seed`) whose modules form
the runtime. The building blocks below mirror the build order in
xref:04-solution-strategy.adoc[Solution Strategy].

=== Implemented

* `Seed` — top-level facade and project entry point.
* `Seed.Token` — the token value (type, text, source positions, channel)
  and the well-known token-type constants (`EOF`, invalid type).
* `Seed.Vocabulary` — the mapping from integer token types to literal,
  symbolic, and display names, used for diagnostics and tree rendering.
* `Seed.CharStream` — an immutable character input stream over a UTF-8
  binary, offering lookahead, consume, mark/seek, and text extraction.
* `Seed.TokenStream` — an in-memory buffer of tokens with positional
  lookahead, the bridge between a lexer's output and a parser's input.
* `Seed.IntervalSet` — merged inclusive integer intervals, the symbols a
  set or not-set transition matches.
* `Seed.ATN`, `Seed.ATN.State`, `Seed.ATN.Transition`,
  `Seed.ATN.LexerAction` — the ATN graph as an immutable value: states and
  transitions are single structs discriminated by an atom, and edges
  reference other states by integer number.
* `Seed.ATNDeserializer` — reconstructs the ATN from the tool's serialized
  integer stream, validated against the canonical runtime
  (xref:09-architecture-decisions.adoc#adr-002[ADR-002]).
* `Seed.ATN.PredictionContext`, `Seed.ATN.ATNConfig`,
  `Seed.ATN.ATNConfigSet`, `Seed.ATN.LexerActionExecutor` — the
  configuration and call-stack types the simulators reason over.
* `Seed.LexerATNSimulator` — matches one token by simulating the lexer
  ATN (closure, reach, longest-match rollback), without the DFA cache.
* `Seed.Lexer` — the token-producing driver: lexer commands, modes, and
  emission. Validated against the reference lexer's token streams.

* `Seed.ATN.PredictionContext` (array form + merge), `Seed.ATN.SemanticContext`,
  `Seed.ATN.ParserATNConfigSet` (context-merging), and `Seed.ATN.PredictionMode`
  — the parser prediction data layer.
* `Seed.ParserATNSimulator` — adaptive LL(*) prediction (SLL stage) with the
  left-recursion precedence filter, without the DFA cache.
* `Seed.Parser` and `Seed.ParserInterpreter` — the ATN-walking tree builder,
  including left-recursion. Validated against the reference parser's trees.

=== Planned

* *Lexer DFA cache* — an ETS-backed memoization of lexer decisions
  (xref:09-architecture-decisions.adoc#adr-005[ADR-005]); a pure
  optimization over the current simulator.
* *Full-context (LL) fallback* — for grammars that are ambiguous under SLL.
* *Code generation* — the Elixir target that emits a parser from a grammar.
* *Recognizer bases* — lexer and parser base behaviours, error listeners
  and recovery strategy, parse-tree nodes, and the tree walker.
* *Code generation* — the Elixir target that turns a grammar into a Seed
  parser module.
